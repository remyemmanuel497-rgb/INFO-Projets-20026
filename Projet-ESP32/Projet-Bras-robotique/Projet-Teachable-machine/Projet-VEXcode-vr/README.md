# Suivi de ligne avec VEXcode VR

## Objectif du projet
Programmer le robot virtuel de VEXcode VR afin qu'il puisse suivre automatiquement une ligne tracée au sol.

## Outils utilisés
- VEXcode VR
- Capteur Eye Sensor
- Ordinateur avec navigateur Web

## Fonctionnement du projet
Le robot utilise son capteur Eye Sensor pour détecter la couleur de la ligne au sol.

- Lorsque le capteur détecte la ligne, le robot ajuste sa direction.
- Lorsque le capteur ne détecte plus la ligne, il corrige sa trajectoire.
- Le programme répète cette opération en continu afin de rester sur le parcours.

## Résultats obtenus
Le robot suit la ligne de manière autonome sans intervention de l'utilisateur. Il corrige sa trajectoire lorsqu'il s'éloigne de la ligne.
