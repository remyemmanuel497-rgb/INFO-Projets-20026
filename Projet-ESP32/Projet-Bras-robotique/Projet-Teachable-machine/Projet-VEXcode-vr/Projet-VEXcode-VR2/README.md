# Détection d'obstacle avec VEXcode VR

## Objectif du projet
Programmer le robot virtuel pour détecter un obstacle et changer automatiquement de direction afin d'éviter une collision.

## Outils utilisés
- VEXcode VR
- Distance Sensor
- Ordinateur avec navigateur Web

## Fonctionnement du projet
Le robot avance en ligne droite tout en surveillant la distance devant lui.

- Si aucun obstacle n'est détecté, le robot continue d'avancer.
- Lorsqu'un obstacle est détecté à une distance définie, le robot s'arrête.
- Il effectue un virage puis reprend son déplacement dans une nouvelle direction.

## Résultats obtenus
Le robot détecte correctement les obstacles présents sur le terrain et modifie sa trajectoire pour éviter les collisions.
