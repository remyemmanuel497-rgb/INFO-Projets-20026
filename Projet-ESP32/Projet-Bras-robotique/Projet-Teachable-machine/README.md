# Reconnaissance d'objets et des sons avec l'IA

## Objectif du projet
Entraîner une intelligence artificielle à reconnaître différents objets  et des sons via une webcam et un microphone.

## Outils utilisés
- Teachable Machine
- Webcam
- Microphone
- Navigateur Web

## Fonctionnement
Des images et des sons  sont collectées pour chaque classe.
Le modèle est entraîné puis teste la reconnaissance en temps réel.

## Résultats obtenus
Le modèle reconnaît correctement les objets etsons appris.
