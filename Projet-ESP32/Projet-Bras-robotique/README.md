# Bras Robotique avec Arduino

## Objectif du projet
Contrôler un bras robotique à l'aide de servomoteurs.

## Composants utilisés
- Arduino Uno
- 3 servomoteurs
- Tinkercard

## Fonctionnement
Les servomoteurs se déplacent vers des positions précises définies dans le programme.

## Résultats obtenus
Le bras robotique effectue correctement les mouvements programmés.
