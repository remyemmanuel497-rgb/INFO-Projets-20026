
# Projet ESP32 avec DHT22

## Objectif du projet
Créer un système qui mesure automatiquement la température et l'humidité.

## Composants utilisés
- ESP32
- Capteur DHT22
- LED rouge
- Wokwi

## Fonctionnement
L'ESP32 lit les données du capteur DHT22.
Si la température dépasse une valeur définie, la LED s'allume.
Les valeurs sont affichées dans le Serial Monitor.

## Résultats obtenus
Le système mesure correctement la température et l'humidité.
La LED réagit selon les conditions programmées.
